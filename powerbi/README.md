# Dashboard no Power BI

Sugestão de páginas e indicadores:

## Página 1 - Visão Geral
- Faturamento total
- Quantidade de vendas
- Ticket médio
- Clientes ativos
- Faturamento por mês

## Página 2 - Produtos
- Top 5 produtos por faturamento
- Unidades vendidas por produto
- Faturamento por categoria
- Produtos com estoque baixo

## Página 3 - Clientes
- Vendas por cidade
- Clientes com maior faturamento
- Quantidade de clientes ativos

## Fonte de dados
Conecte o Power BI ao PostgreSQL do projeto e use as tabelas:
- clientes
- produtos
- vendas

Também é possível importar `data/vendas_tratadas.csv` para demonstrar a etapa de tratamento com Pandas/Numpy.
